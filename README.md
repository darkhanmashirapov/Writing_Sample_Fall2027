# Geopolitical Shock Transmission in Emerging Bond Markets
### Evidence from Kazakhstan and Russia

**Author:** Darkhan Mashirapov

## Overview

This repository contains the data, code, and written analysis for an
empirical study examining whether the Russia–Ukraine war altered the
relationship between corporate credit-risk spreads and macro-financial
conditions in Kazakhstan and Russia.

The analysis investigates long-run relationships, short-run adjustment,
and changes in spread dynamics across regimes, combining several
complementary time-series methods.

## Methodology

The empirical workflow includes:

1. **Data preparation:** collection, cleaning, merging, and transformation
   of bond-market and macro-financial data.
2. **Exploratory analysis:** visualization and examination of the
   statistical properties of the series.
3. **ARDL estimation and bounds testing:** assessment of long-run
   relationships and short-run dynamics between credit spreads and
   macro-financial variables.
4. **Markov-switching estimation:** identification of distinct regimes
   in spread dynamics.
5. **Vector autoregression and impulse response analysis:** examination
   of the dynamic responses of credit spreads to macro-financial shocks.

The written study discusses the empirical findings, their interpretation,
and the limitations of the analysis.

The consolidated workbook, `master_dataset_final.xlsx`, is located in
`1. Data/` and contains three sheets:

| Sheet | Description |
|---|---|
| `Levels` | Merged series in levels, before statistical transformations. |
| `Transformed` | Transformed series prepared for econometric analysis. |
| `Codebook` | Variable definitions and accompanying documentation. |

Refer to the codebook and the written study for details on the data
and variable construction.

## Software Requirements

The analysis uses Python 3 with the following packages:

- `pandas`
- `numpy`
- `statsmodels`
- `matplotlib`
- `seaborn`
- `openpyxl`

Jupyter Notebook or JupyterLab is required to run the notebooks.

Install the packages using:

    python -m pip install pandas numpy statsmodels matplotlib seaborn openpyxl jupyterlab

## Running the Analysis

1. Download or clone the repository, preserving its folder structure.
2. Install the required Python packages.
3. Check the input and output paths in the notebooks and adjust them
   to match your local working directory.
4. Open `2. Scripts/` in Jupyter Notebook or JupyterLab.
5. Execute the notebooks in numeric order, running each notebook's
   cells from top to bottom.

The workflow is sequential: later notebooks depend on intermediate
outputs generated by earlier steps.

For the research discussion and interpretation of the results, consult
the study in `3. Report/`.
